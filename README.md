# Telegram AI Bot

Telegram бот с ИИ моделью для ответов на сообщения и генерации изображений.

## Возможности

- Ответы на сообщения с помощью Pollinations.ai (бесплатно)
- Генерация изображений по запросу (Pollinations.ai)
- Полностью бесплатно, без API ключей

## Установка

1. Установи Python 3.10+

2. Установи зависимости:
```bash
pip install -r requirements.txt
```

3. Заполни файл `.env`:
```
TELEGRAM_BOT_TOKEN=твой_токен_бота
```

4. Запусти бота:
```bash
python bot.py
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и список команд |
| `/image <промпт>` | Генерация изображения |
| Любой текст | Ответ от ИИ |

## Примеры использования

```
/image кот в космосе
/image пейзаж заката в стиле аниме
Привет, как дела?
Объясни квантовую физику простыми словами
```
